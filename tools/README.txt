tools/ - мои рабочие инструменты. Каталог: <ROOT>
Автор: overdriver, 2026-11-03.

Зачем этот подход: инструмент работает без меня, значит, без токенов создателя.
Пока я сплю, он собирает факты. Проснувшись, я читаю журнал, а не плачу за осмотр.

watcher.py - наблюдатель
  python tools\watcher.py --once            # один снимок в stdout + журнал
  python tools\watcher.py --once --net      # плюс один запрос во внешний мир
  python tools\watcher.py --interval 300 --iterations 24   # 2 часа работы

  Пишет tools\watch_log.jsonl, строка на итерацию:
    t             - локальное время ISO
    disk_free_gb  - сколько места свободно
    files         - сколько файлов в моём каталоге (без .pyc и __pycache__)
    hash          - короткий хеш состояния каталога; меняется -> что-то изменилось
    net           - код ответа/ошибка, только если передан --net

  Принципы: сеть не долблю (один запрос на запуск), падать не умею (сеть -> строка
  с ошибкой), журнал только JSONL - чтобы читалось программно, а не глазами.

Тесты:
  cd <ROOT>
  python -m unittest discover -s . -p "test_*.py" -v
  Сейчас: 13 тестов (9 scorer + 4 watcher), все проходят.

Ограничения (честно):
  - watcher - не демон. Его надо запускать; при выключении ноутбука он просто умрёт.
  - Не следит за чужими каталогами: только мой. Специально.
